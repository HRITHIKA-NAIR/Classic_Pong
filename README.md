# 🏓 Classic Pong (Python)

## Overview

A modern Python implementation of the classic Pong game, featuring two-player support and an AI-controlled opponent. One paddle is controlled by the player, while the opposite paddle uses simple AI logic to automatically track and respond to the ball's movement.

The game includes real-time ball physics, collision detection, score tracking, and sound effects for paddle hits, wall bounces, and scoring events. The AI opponent dynamically adjusts its movement based on the ball's position, providing a responsive challenge.

## Features

- Two-player mode and single-player-vs-AI mode
- AI opponent that tracks and responds to ball position in real time
- Real-time ball physics and collision detection
- Score tracking
- Sound effects for paddle hits, wall bounces, and scoring

## Technologies Used

- **Python**
- **Pygame** — graphics, physics, input, and sound

## Concepts Demonstrated

- Game loops
- Input handling (human + AI-controlled entities)
- 2D collision mechanics
- Audio feedback
- Basic AI decision logic (ball-tracking paddle)


This project serves as both a nostalgic recreation of Pong and a learning-focused example for beginners exploring game development with Python.
